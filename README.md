# 绒绒独立桌面宠物

绒绒是一只可爱的小精灵桌面宠物，支持鼠标追视、拖动、动作反馈和对话气泡。

## 启动

Windows 下双击 `启动绒绒.bat`。也可以在项目目录运行：

```text
py main.py
```

需要 Python 3.10 或更高版本，并安装 Pillow：

```text
py -m pip install Pillow
```

## 操作

- 左键点击：随机触发笑、惊吓、弹跳或沮丧动作。
- 左键拖动：绒绒跟随鼠标移动并播放奔跑动作。
- 鼠标移动到绒绒附近：视线跟随鼠标；鼠标停下约 1 秒后恢复正面。
- 鼠标滚轮：调整大小，大小会保存在 `settings.json`。
- 右键点击：退出程序。
